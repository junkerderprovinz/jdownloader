## 2. What it does

- **Selkies instead of noVNC.** A hybrid VNC and H.264 stream for a smooth desktop at 60 fps, a real clipboard in both directions, and file upload and download from the browser.
- **Dark everywhere.** A monochrome IBM Carbon `#161616` palette covers the download list, the LinkGrabber and the settings, not only the menu bar. One variable switches to a matching light theme or to JDownloader's classic look.
- **No ads.** The premium banner, the nag columns and the deal popups are switched off, so the speed graph keeps its full height.
- **Nothing to set up.** JDownloader installs itself on the first start and updates itself as usual, with Java 21 for the full Swing GUI.
- **Your settings survive updates.** Links, accounts and session state live in `/config`, and the image runs on amd64 and arm64.

## 4. Getting started

On Unraid, install JDownloader from [Community Applications](https://ca.unraid.net/apps/jdownloader-18m0vwh17mexzh). The defaults work as they are: `/config` goes to `/mnt/user/appdata/jdownloader` and downloads to `/mnt/user/downloads`. Set a WebUI password if the server can be reached from outside your network.

> [!IMPORTANT]
> On the first start, and after every image update, JDownloader installs or updates itself and the WebUI stays black for a few minutes. Wait for `JDOWNLOADER IS READY` in the container log before you open it, and do not restart the container in the meantime.

Then open `https://<server-ip>:3001/` and accept the self-signed certificate once. The Selkies client needs HTTPS for its video decoder and for the clipboard. Port `3000` is plain HTTP and only works behind a reverse proxy that handles TLS.

Without Unraid:

```bash
docker run -d --name jdownloader --shm-size=1gb \
  -p 3001:3001 \
  -e PUID=99 -e PGID=100 \
  -v /path/to/appdata/jdownloader:/config \
  -v /path/to/downloads:/downloads \
  junkerderprovinz/jdownloader:latest
```

`--shm-size=1gb` keeps Selkies rendering smooth; the Unraid template sets it for you. The interface starts in English, and JDownloader's own settings switch the language.
